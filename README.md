# Portfolio website for GitHub Pages

This is a responsive static portfolio built with HTML and CSS. No build tools are required.

## Before publishing
1. Open `index.html`.
2. Replace every instance of `Your Name` / `YOUR NAME` with your name.
3. Replace `YN` with your initials.
4. Update the email, LinkedIn and GitHub links in the Contact section.
5. Review project descriptions and only keep claims that accurately describe your work.

## Publish with GitHub Pages
1. Sign in to https://github.com/ (create an account if needed).
2. Click **New repository**.
3. Name the repository exactly `YOUR-USERNAME.github.io` for the simplest URL.
4. Choose **Public**, then create the repository.
5. Click **Add file → Upload files** and upload `index.html` (you can also upload this README).
6. Click **Commit changes**.
7. Open **Settings → Pages**. If prompted, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then **Save**.
8. Wait a minute or two and open `https://YOUR-USERNAME.github.io/`.

If you use a repository named `portfolio` instead, the URL will usually be `https://YOUR-USERNAME.github.io/portfolio/`.

## Note
The URL depends on your actual GitHub username. This folder does not publish itself; you must upload it to your GitHub account and enable Pages.
